# NeuroTestix organization profile

The public [NeuroTestix GitHub overview](https://github.com/NeuroTestix) is rendered from [profile/README.md](profile/README.md).

## Assets

The profile uses the approved NeuroTestix visual identity and screenshots of the public landing at [ntx42.com](https://ntx42.com/). Assets are kept in this public repository so the organization overview does not depend on access to a private repository.

- `profile/assets/logo-horizontal-light.svg` and `logo-horizontal-dark.svg`: original revision-rail mark with an outlined Inter wordmark, selected for the viewer's color theme.
- `profile/assets/desktop.png`: the public landing at desktop size.
- `profile/assets/worked-example.png`: the hand-curated interval-merge illustration; it is not a model result.

The SVGs contain vector paths and no external fonts or resources. Inter is licensed under the [SIL Open Font License 1.1](https://github.com/rsms/inter/blob/master/LICENSE.txt). The illustration and visual identity were created for NeuroTestix.

## Maintenance

Keep the early research status explicit. Do not describe a checkpoint, model advantage, confirmed finding or product release without supporting evidence. Update screenshots alongside visible changes to the public site.
